## Root integration contract

All classes live in `com.github.standobyte.jojo.fabric.stand.tracking`.

1. Call `TrackingHooks.initialize()` during common initialization, before world loading. Register `StandTrackingGameTests` with the existing real GameTest discovery mechanism.
2. Call `TrackingHooks.entityChanged(Entity)` after real item/equipment/container-entity changes and entity load; bind horse inventories with `inventoryChanged(LivingEntity,Container)`. Call `containerChanged(ServerLevel,BlockPos,Container)` after block-container changes/load. Do not call these for presentation copies or recipe previews.
3. Call `playerJoin(ServerPlayer)` and `playerTick(ServerPlayer)` from the existing single player lifecycle. Call `livingTick(LivingEntity)` from the unfrozen living lifecycle for public effect presentation; it does not execute server effect gameplay. The existing `StandEffects.tick` remains the only effect tick. `StandEffectStore.ownerChanged` after effect add/remove makes inverse-target queries available immediately. On tracking start call `StandEffectStore.syncTo(LivingEntity,ServerPlayer)`.
4. Projectile creation uses `projectileCreated(Entity,ItemStack,boolean detachIdentityFromSource)` before source-stack consumption. Only the center multishot projectile receives the identity; secondary ammo copies clear `TrackedItemIdentity.COMPONENT` before construction. Root may connect modern common arrow constructors, but KnifeItem constructs its projectile from a fresh unmarked default stack and needs the original hand stack passed explicitly. Successful arrow/knife embedding uses `projectileEmbedded(Entity,LivingEntity,boolean knife)` at the exact successful embedded-count update. Pickup uses `projectilePickup(Entity,ItemStack)` where subclass pickup copies would otherwise omit the stored identity.
5. Blade Hat's private `thrownStack` requires an authoritative raw getter/setter adapter registered with `ItemTrackingService.registerEntityItem(Class<? extends Entity>,Function<Entity,ItemStack>,ConsumerPair)`. `getThrownStack()` returns a copy and must not be used as the slot getter. The modern common arrow pickup origin is handled directly; explicit adapters override that default.
6. Before a validated merchant cost is consumed, call `TrackingHooks.traded(Entity,ItemStack)` for each marked cost. Cancel/consume trading interaction when `refuseInteraction` returns true. At the original extra Mob pickup pass, iterate `markedPickupCandidates(Mob)` and invoke vanilla protected `pickUpItem(ServerLevel,ItemEntity)`; do not apply the ordinary canPickUpLoot gate.
7. Register client receivers for `ItemTrackingPayload.TYPE` → `ItemTrackingPayload.receive(player,payload)` and `ItemTrackingPayload.Effects.TYPE` → `StandEffectStore.receive(level,payload)`. Clear client caches on disconnect with `ItemTrackingPayload.clearClient()` and `StandEffectStore.clearRuntime()`. Clear all session caches via `TrackingHooks.clearRuntime()` when the server stops.
8. On a newly looked-at actual entity, send `new ItemTrackingPayload.Encounter(entity.getId())` when `LifeformSubtypes.matching(entity)` includes a key absent from `LifeformsEncountered.values(player)`. The server validates actual range and derives all variants.50 owns the original toast/sound and GE selection UI.
9. Plan52 calls `LifeformSubtypes.registerCocoJumbo(Consumer<Entity> grantMrPresident,Predicate<Entity> hasMrPresident)` after registering its actual actor-owned turtle. The variant stays unavailable until that concrete contract exists. Root76 Extra now carries base selection plus optional subtype;48 must validate both against this catalog.

## Shared feature APIs

- `mark(ServerPlayer,ItemStack)` returns an optional stable identity. Mark actions split exactly one item first;47 does not invent the GE action's hand-swapping rules.
- `resolve(ServerPlayer,UUID)` returns an optional actual `Resolved` holder; `extract(ServerPlayer,UUID)` validates registration/current dimension, removes the actual source once and returns `Extracted`. Feature actions still enforce their original range/eligibility before extraction. `unmark` and `restoreRegistration` support the concrete persisted GE mark effect.
- `ItemTrackingPayload.views(Player)` exposes owner-only current-dimension client markers. `View.marker(Level,float)` follows actual client entities. No client packet can submit a holder, stack or tracking position.
- `StandEffectStore.getTargetLookedAt(owner,type,range)` returns `Optional<StandEffects.Entry>`; `target(owner,entry)` resolves server or client public state. `targeting(target,type)` provides linked loaded owner/effect pairs for reflection and theft interactions. Concrete handlers use the existing `StandEffects.register/add/remove` API.
- `LifeformsEncountered.eligible(user,key)` requires a supported, encountered key and the source predicate. Unknown saved mod IDs remain preserved but cannot be selected. `LifeformSubtypes.create` creates a fresh entity; `isValid` uses a world-scoped original-style prototype cache.

## Persistence and trust boundaries

Tracked item components store only immutable ID/owner. Owner attachment stores version1 registrations and holder UUID/dimension or block position/type. Actual holder checks run before every resolution/extraction; no position-only fallback, chunk forcing or client-owned stack reconstruction exists. The same identity cannot become two extractable items. Missing/unloaded holders keep durable identity but produce no marker. Entity-carried trade/projectile objects use a separate version-compatible serialized attachment; ordinary inventories remain authoritative vanilla storage.

Limits protect saved/network trust boundaries:128 marks/effects/carried items,4096 discovered/native IDs, bounded identifier and subtype strings, owner-only item snapshots, and existing StandEffects64KiB handler payload limit. These are defensive serialization limits, not new action costs/cooldowns. Registry unknown IDs stay preserved in encounter saves and are rejected at use time. Modern inventory components replace Forge capability-tag hacks; no Forge-world import or save rewrite is claimed.
