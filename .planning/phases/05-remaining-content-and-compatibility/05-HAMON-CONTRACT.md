# Shared Hamon API contract

- `com.github.standobyte.jojo.core.HamonProgress` is immutable persistent state. `hamon`, `energy`, `breathStability`, `strengthPoints`, `controlPoints`, `strengthLevel`, `controlLevel`, `breathingLevel`, `hasSkill(String)`, `technique` (empty when absent), `exerciseTicks(Exercise)`, `exerciseMaxTicks(Exercise)`, `trainingBonus`, `skipDays`.
- `HamonService.state(LivingEntity)`, `hasHamon(LivingEntity)`, `efficiency(entity,cost[,skill])`, `consumeEnergy(entity,cost[,skill])` (returns pre-consumption efficiency), `gainActionPoints(entity,boolean strength,float energyUsed)`, `bloodstreamEfficiency(entity)`. Server authoritative; NPCs supported.
- `grant`, `clear`, `grantMaster`, `setStats(entity,int strengthPoints,int controlPoints)`, `setBreathing(entity,float)`, `setMeditating(entity,boolean)`, `isMeditating`, `setBreathingHeld(entity,boolean)`, `isBreathingHeld`, `energy(entity,float)`, `breathStability(entity,float,int noRecoveryTicks)`, `interactTeacher(ServerPlayer,LivingEntity)`.
- `HamonSkills` exposes every original skill/technique definition, dependencies, trees/tier, teacher requirement, perks and action unlocks. Agent publishes exact metadata record/accessor signatures to client as soon as defined.
- `HamonPayload(Operation operation,String id,int targetId,boolean enabled)`: OPEN, READ_INTRO, LEARN, TECHNIQUE, RESET, MEDITATE, ABANDON, ASK, TEACH. Bound strings and validate every server request; nearby teacher skill union is server synchronized.
- `HamonActionPayload(String action,Operation operation)`: START, KEEP, RELEASE, CANCEL, LEAP. `HamonActionCatalog` supplies action metadata, default rows, shift variants and original locks. Action runtime state synchronizes held action/charge/cooldowns/continuous action and public render flags.
- Root provides `HamonItems.consumeSoap(LivingEntity,int)` -> `SoapSource` BOTTLE/GLOVES/NONE; `soapItem(LivingEntity)`, `soapHasAmmo(LivingEntity,int)`; `lifeMagnetism(ServerPlayer,BlockHitResult,float energy)` boolean and `GLIDER_MAX_ENERGY`. Original soap source priority/creative consumption rules preserved.
- Root provides items, Clackers/Crimson Bubble/Leaves Glider, teacher NPC/temple, advancement wiring, existing VampireHamon integration and shared initializer/build/mixin JSON.
- Progression worker owns core state/skills/config/service/UI payload/training hooks. Action worker owns action catalog/runtime/action payload/effects/projectiles/passive combat and movement hooks. Client worker owns all common HUD/menu/input integration and new Hamon UI/presentation classes. Root owns item/teacher/transport renderers; coordinate IDs first.
